Demande de suppression de données — Vitality RPG

Application : Vitality RPG · Éditeur : Vindict Studio
Dernière mise à jour : 8 juillet 2026

Vous pouvez demander la suppression d’une partie ou de la totalité de vos données cloud sans supprimer votre compte.

  1. Envoyez un e-mail à contact@vindicttechnology.com
  2. Objet : Suppression de données Vitality RPG
  3. Indiquez l’adresse e-mail (ou identifiant) liée au compte
  4. Précisez les données à supprimer (voir liste ci-dessous)
  5. Confirmez : « Je souhaite conserver mon compte »

Nous confirmons la demande sous 7 jours et traitons la suppression sous 30 jours.

Exemples de demandes possibles

Données Action possible
Pseudo / profil public Suppression ou anonymisation
Scores et classements amis Retrait des classements / synchronisation sociale
Duels et historique de défis Suppression ou anonymisation
Avatar cloud (si présent) Suppression
Autres données cloud liées au compte Suppression partielle sur demande

Ce qui reste après une suppression partielle

  • Votre compte (connexion e-mail / Google / Apple) reste actif, sauf si vous demandez aussi sa suppression.
  • Les données stockées uniquement sur votre appareil (progression locale) ne sont pas effacées par cette demande. Vous pouvez les supprimer en désinstallant l’app ou via une réinitialisation dans l’app.
  • Les preuves de transaction d’achat restent chez Google Play / App Store selon leurs obligations.

Différence avec la suppression de compte

  • Cette page : suppression de données, compte conservé.
  • Suppression de compte : fermeture définitive du compte et des données associées.
